# เพิ่มวิชาส่วนตัวด้วยชื่ออย่างเดียว

ชื่อวิชาเป็นป้ายของกลุ่มคะแนนที่ผู้ใช้ตั้งเอง ไม่เรียกหรือสร้างทะเบียนรายวิชากลาง
STUDENT เพิ่มวิชาได้ โดย backend ระบุ owner_core_user_id จากผู้ใช้ที่ผ่าน SSO เท่านั้น
งานนี้เพิ่มเฉพาะสิทธิ์ COURSE_CREATE; สิทธิ์แก้ไข/ลบวิชาเดิมไม่เปลี่ยน

ชื่อวิชาต้องไม่ว่าง; รหัสวิชาและหน่วยกิตไม่บังคับและเก็บ NULL เมื่อไม่ระบุ
ไม่สร้างรหัสปลอมหรือหน่วยกิตอัตโนมัติ ไม่ระบุหน่วยกิตก็ยังคำนวณคะแนนได้
GPA ยังไม่อยู่ในงานนี้; สถิติหน่วยกิตรวมเฉพาะค่าที่ระบุ
ข้อมูลเดิมไม่ถูกลบ: migration เปลี่ยนแค่ความสามารถรับ NULL ของสองคอลัมน์

หลังติดตั้งให้ generate/build/test และรัน Docker เพื่อให้ migrate deploy ทำงาน
ห้ามใช้ prisma migrate reset หรือ docker compose down -v
ต้องให้ PL review การเปลี่ยนสิทธิ์และขอบเขตรายวิชาส่วนตัวก่อน merge/deploy
หลัง deploy ให้นักศึกษา login ใหม่ ทดสอบชื่ออย่างเดียว รีเฟรช และบันทึกคะแนน
ยังไม่อ้างว่าทดสอบ production ผ่านจนมีผลจริง
