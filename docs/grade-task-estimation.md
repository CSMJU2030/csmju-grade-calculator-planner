# ประมาณคะแนนเต็มของงาน

ใช้ส่วน "ประมาณคะแนนเต็มของงาน" ในหน้าคำนวณเกรด เมื่อรู้คะแนนเต็มรวมของกลุ่ม แต่ยังไม่ทราบคะแนนเต็มของบางงาน

สูตร: (คะแนนเต็มรวม − คะแนนเต็มของงานที่ทราบ) ÷ จำนวนงานที่ยังไม่ทราบคะแนนเต็ม

ตัวอย่าง: เต็มรวม 60 คะแนน มี 5 งาน รู้คะแนนเต็ม 10 และ 20 คะแนน อีก 3 งานจะประมาณงานละ 10 คะแนน หากเพิ่มงานที่ไม่ทราบอีก 1 งาน จะเป็น 30 ÷ 4 = 7.5 คะแนน หากงานนั้นประกาศคะแนนเต็มแล้ว ให้กรอกในช่องคะแนนเต็มที่อาจารย์แจ้ง ระบบใช้ค่าจริงและแบ่งส่วนที่เหลือใหม่

## วิธีใช้

1. กรอกคะแนนเต็มรวม เช่น 60
2. กรอกน้ำหนักของกลุ่มงานในรายวิชา เช่น 30%
3. เพิ่มงานทั้งหมดในกลุ่ม เช่น 5 งาน
4. กรอกคะแนนเต็มเฉพาะงานที่ทราบ เช่น 10 และ 20 เว้นอีก 3 ช่องว่าง
5. กรอกคะแนนที่ทำได้เฉพาะงานที่ประกาศผลแล้ว

น้ำหนักแต่ละงาน = คะแนนเต็มของงาน ÷ คะแนนเต็มรวม × น้ำหนักกลุ่ม การคิดเช่นนี้สมมติว่าคะแนนแต่ละแต้มมีค่าเท่ากันภายในกลุ่ม หากอาจารย์กำหนดน้ำหนักเฉพาะงานต่างกัน ให้ใช้รายการคะแนนปกติแทน ห้ามใส่งานกลุ่มเดียวกันซ้ำทั้งสองส่วน

คะแนนที่ได้ว่าง = ยังไม่ทราบ ไม่ใช่ศูนย์; กรอก 0 = ทราบว่าได้ศูนย์คะแนน โปรแกรมไม่สร้างคะแนนที่นักศึกษาทำได้เอง

คะแนนเต็มโดยประมาณจะไม่เขียนทับช่องที่เว้นว่าง จึงคำนวณใหม่ได้เมื่อเพิ่ม/ลบงาน เมื่อยังใช้ค่าประมาณจะติดป้ายผลเกรดโดยประมาณ ทุกงานทราบคะแนนเต็มแล้วต้องรวมตรงกับคะแนนเต็มรวม

โปรแกรมไม่ใช้ค่าติดลบ คะแนนเต็มเป็นศูนย์ คะแนนเต็มรวมไม่ตรง น้ำหนักรวมเกิน 100% หรือคะแนนที่ได้เกินคะแนนเต็ม หากไม่ถูกต้องจะแสดงข้อความและหยุดผลคำนวณเกรด ไม่ใช้ข้อมูลบางส่วนเพื่อแสดงเกรดที่คลาดเคลื่อน

ตัวเลขแสดงผลปัดเพื่อให้อ่านง่าย แต่สูตรใช้ค่าก่อนปัด ข้อมูลหน้านี้เป็นการทดลองชั่วคราวและหายเมื่อโหลดหน้าใหม่ ยังไม่บันทึกลงฐานข้อมูล

## โค้ดและการตรวจ

- `frontend/src/lib/task-estimation.ts`: สูตรแบ่งคะแนนเต็มและตรวจข้อมูล
- `frontend/src/components/features/task-estimator.tsx`: ฟอร์มเฉพาะงาน ประกอบจาก `@/csmju` และ token เดิม
- `frontend/src/components/features/grade-calculator.tsx`: รวมรายการธรรมดาและกลุ่มงานในผลเกรด

ใช้ PageHeader/StatusBadge/ConfirmDeleteModal/class input/card/button จากส่วนกลางตามเดิม ไม่แก้ `src/csmju/` หรือ `globals.css` ไม่เพิ่ม package ไม่เปลี่ยน auth/database

สคริปต์ `apply-grade-estimation.py` รวมการติดตั้ง template ฉบับก่อนและฟีเจอร์นี้ไว้ในชุดเดียว เป็น ASCII ทั้งไฟล์ ติดตั้งได้ทั้งจาก snapshot เดิมและจากฉบับ template ที่เพิ่งส่งให้ หยุดก่อนเขียนหากไฟล์ถูกแก้ต่อในส่วนที่ต้องเปลี่ยน สำรองไฟล์ก่อนติดตั้ง ใช้ `--check` เพื่อตรวจโดยไม่เขียน และ `--restore <backup>` เพื่อคืนไฟล์หากยังไม่ได้แก้ต่อ

ทดสอบบน Mac: หยุด frontend/backend ที่กำลัง watch ก่อน แล้วรัน backend build/test และ frontend build จากราก repo ตรวจตัวอย่าง 60/10/20/3 งาน เพิ่มงานใหม่แล้วได้ 7.5 กรอกคะแนนเต็มจริงแล้วค่าเปลี่ยน กรอกศูนย์ในคะแนนที่ได้แล้วต้องถือว่าทราบคะแนนแล้ว และกรอกคะแนนเต็มเกินยอดรวมแล้วต้องไม่แสดงผลเกรด
